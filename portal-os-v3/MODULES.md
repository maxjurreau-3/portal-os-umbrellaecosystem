# Portal‑OS‑v3 Modules  
Umbrella Ecosystem Engine Layer

## SIM Engine
The foundational simulation engine.  
Provides heartbeat (`sim:tick`), initialization, and state tracking.

## Operators Engine
Action + automation engine.  
Registers actions, runs them, and emits operator events.

## XR Engine
Extended Reality engine.  
Activation/deactivation and XR state management.

## Identity‑Physics Engine
Identity + physics entity system.  
Creates entities and tracks identity‑physics state.

## Games Engine
Game registry + interactive engine.  
Allows games to be registered and listed.

## Shared Utils
Utility functions used across engines.
